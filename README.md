# Bonian Nabil Website

A modern corporate website designed and developed for **Bonian Nabil**, a company specializing in construction and interior design.

The website focuses on presenting the company's services, projects, and information through a clean, professional, and responsive interface.

## ✨ Features

* Modern and professional corporate UI
* Responsive design for desktop, tablet, and mobile devices
* Structured presentation of company services and projects
* Clean and user-friendly navigation
* Reusable React components
* Responsive layouts using Bootstrap
* Cross-device compatible design

## 🛠️ Tech Stack

* **React.js**
* **Bootstrap 5**
* **JavaScript**
* **HTML5**
* **CSS3**
* **Bootstrap Icons**

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm

### Installation

Clone the repository and navigate to the project folder:

```bash
git clone <repository-url>
cd <project-folder>
```

Install the project dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application will run locally in your browser.
